# Agents

Skills for running many coding agents at once.

## Model-invoked

The agent can start these on its own when your request matches.

- **[herdr-orchestration](./herdr-orchestration/SKILL.md)**: Start, prompt, wait for and close Claude or Codex agents in other Herdr tabs. Holds dated notes on Codex model, effort and tier flags.
- **[supervise-agents](./supervise-agents/SKILL.md)**: Run long multi-agent work with one accountable supervisor, bounded workers, independent checks, and evidence for every claim.
- **[spawn-agent-terminal](./spawn-agent-terminal/SKILL.md)**: Open Codex or Claude in a new Windows Terminal tab from WSL, with a first prompt.
