# Writing

Skills for writing messages and explaining things in plain English.

## User-invoked

Only you can start these, by typing the name (`/grounded` in Claude Code, `$grounded` in Codex).

- **[grounded](./grounded/SKILL.md)**: Explain something at full depth in very simple English, built up from the basics a newcomer needs.
- **[simple](./simple/SKILL.md)**: Rewrite the last reply in short, plain English.

## Model-invoked

- **[personal-writing-voice](./personal-writing-voice/SKILL.md)**: Draft or clean up a message to a person so it reads like a person wrote it. Swap `references/EXAMPLES.md` for your own messages to make it sound like you.
